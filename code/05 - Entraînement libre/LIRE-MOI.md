# Entraînement libre

Ce dossier correspond à la page **Entraînement libre** visible dans PJJoue.

- `contenu.html` = ce que la page affiche.
- `style-de-la-page.css` = les règles CSS qui concernent uniquement cette page quand elles peuvent être isolées sans risque.
- `actions-de-la-page.js` = les actions JavaScript propres à cette page quand elles sont séparables sans changer le fonctionnement.

Les règles ou actions utilisées par plusieurs pages restent dans **01 - Éléments communs**. C'est volontaire : on évite de copier le même code à plusieurs endroits.
