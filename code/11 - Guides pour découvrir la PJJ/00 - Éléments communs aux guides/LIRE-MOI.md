# Éléments communs aux guides

Ce dossier contient seulement ce qui sert à **plusieurs pages guides à la fois**.

- `style-commun-des-guides.css` : apparence commune des guides. Chaque guide garde aussi sa propre `style-de-la-page.css` dans son dossier.
- `actions-des-videos.js` : transforme le bouton « Lire la vidéo » en lecteur YouTube lorsque la personne clique dessus.
- `suivi-analytics-des-pages-guides.js` : indique à Google Analytics quelle page guide a été consultée.

Si une modification ne concerne qu’un seul guide, il faut la faire dans le dossier de ce guide et non ici.
