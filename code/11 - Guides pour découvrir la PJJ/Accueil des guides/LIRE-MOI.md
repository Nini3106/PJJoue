# Accueil des guides

Porte d’entrée des guides publics de Quiz CJPM, accessible depuis le menu principal.

Les cinq guides CJPM sont présentés en premier, dans l’ordre des parcours judiciaires. Leur source se trouve dans `code/11 - Guides CJPM/`. Les guides PJJ restent accessibles dans une collection complémentaire optionnelle ; les fiches de repères restent disponibles.

La grille, les cartes et les SVG existants sont conservés. Les nouvelles cartes portent le numéro et les couleurs canoniques de leur parcours. Les styles de lecture sont partagés avec les guides existants.
