# Accueil des guides

Porte d’entrée des guides publics de Quiz CJPM, accessible depuis le menu principal.

Les cinq guides CJPM sont présentés en premier, dans l’ordre des parcours judiciaires. Leur source se trouve dans `code/11 - Guides CJPM/`. Les guides PJJ restent accessibles dans une collection complémentaire optionnelle ; les mesures éducatives et le glossaire CJPM sont classés côté CJPM, et le glossaire PJJ côté PJJ. La rubrique « Prendre ses repères » est supprimée.

La grille, les cartes et les SVG existants sont conservés. Les cinq cartes de parcours portent leur numéro et leur couleur canonique. Les cartes PJJ reprennent les couleurs des thèmes de découverte correspondants. Les styles de lecture sont partagés avec les guides existants.
