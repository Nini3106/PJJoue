# Accueil des guides

Cette page est la porte d’entrée unique vers les guides publics de PJJoue.

- Le bouton **Guides** du menu principal pointe ici.
- Les guides ne sont plus injectés sous la page d’accueil du jeu.
- Les cartes utilisent une iconographie SVG au trait, cohérente avec l’interface PJJoue.
- Les couleurs principales restent celles de PJJoue : bleu profond et jaune.
