# État officiel de PJJoue V1

Date de consolidation : juillet 2026.

## Périmètre

- 150 questions numérotées sans interruption ;
- 100 questions de parcours réparties en 10 étapes égales ;
- 50 questions d’évaluation finale ;
- fonctionnement local et sur hébergement statique HTTPS ;
- progression locale avec export et import JSON ;
- interface adaptée aux différentes tailles d’écran, navigation clavier et réduction des animations ;
- pages de confidentialité, d’accessibilité et de mentions légales.

## Contrôles intégrés

La suite automatique vérifie notamment :

- la cohérence des trois fichiers JSON et du fichier généré ;
- l’ordre officiel des 150 questions et la répartition 100 + 50 ;
- les références de fichiers locales ;
- l’absence de code JavaScript inutilisé, de fonction trop longue ou de ligne illisible ;
- l’absence de règle CSS vide, de sélecteur orphelin, de variable inutilisée et de propriété écrasée ;
- l’unique exception de cascade documentée du composant Progression ;
- les règles de déverrouillage et de bilan de l’étape 11 ;
- l’absence de référence à une autre version du produit ;
- 42 états et interactions dans Chromium, sans erreur JavaScript ;
- les fils jaunes du mode Relier et les textes complets de correction.

## Limites externes

La V1 ne constitue pas à elle seule une validation juridique, une homologation de sécurité ou une déclaration de conformité RGAA. Ces validations dépendent du contenu métier, du contexte de diffusion et de l’hébergement retenu.
