# Vérification éditoriale de la banque

Avant chaque publication :

1. vérifier chaque énoncé, réponse, distracteur, explication et source ;
2. confirmer que chaque lien officiel est encore accessible et pertinent ;
3. dater la dernière vérification ;
4. maintenir une formulation pédagogique indépendante, sans laisser entendre une validation institutionnelle ;
5. reconstruire les données et exécuter tous les tests après chaque modification.

`documentation/audit_contenu.csv` peut servir de registre de suivi éditorial.
