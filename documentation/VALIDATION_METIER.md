# Validation métier de la banque

Avant une diffusion institutionnelle :

1. désigner un propriétaire fonctionnel ;
2. désigner les référents métier et juridiques compétents ;
3. vérifier chaque énoncé, réponse, distracteur, explication et source ;
4. renseigner un statut de contenu explicite ;
5. dater la dernière vérification ;
6. conserver `versionContenu` à `V1` dans cette archive officielle ;
7. reconstruire les données et exécuter tous les tests après chaque modification.

`documentation/audit_contenu.csv` peut servir de registre de suivi de la validation.
